# 寫作習慣

寫講義、簡報、筆記時的習慣。**不是規定**——讀者換了、載體換了就自己調。

下面是本小姐常用的，撞到不適合的情況直接改掉。

## 中英混排

- 中文跟英文、數字之間空一個半形空格：`A4 講義`、`正文 11pt`、`C 多利安`。
- 全形標點前後不空格：`模式（Modes）`、`C 多利安：`。
- CSS 開了 `text-autospace`，忘了空格時會自動補一點點，但 Markdown 預覽和別的工具不會補，手動空格最穩。

## 標點

- 中文句子用全形標點：，。、：；？！（）
- 引號用「」，引號裡面再引用用『』。
- 刪節號用兩個「…」（……），破折號用兩個「—」（——）。
- 英文句子、程式碼裡用半形標點。

## 數字與單位

- 數字用阿拉伯數字。
- 單位直接接在數字後面：`11pt`、`58mm`、`4px`、`16:9`。
- 音級用阿拉伯數字加升降記號：`1`、`♭3`、`♯4`。

## 術語

- 保留原文：日文術語寫片假名（ドリアン），英文術語寫英文（subV7），中文只做說明。
- 第一次出現時補一次說明，用術語表或括號：「ドリアン（Dorian，多利安）」。
- 同一份文件裡，同一個東西只用一種寫法。
- 讀者要靠中文去讀外文原稿的時候（對照講義），反過來寫：中文當主體，外文術語第一次出現時放括號，之後只寫中文；三種寫法收進最後的術語表。

## 和弦與音名

- 升降記號用真的符號：♭（U+266D）、♯（U+266F）、♮（U+266E），不要用 b 和 #。
- 音名用大寫：C、D、E♭。調名寫成「C 大調」「A 小調」「C 多利安」。
- 和弦性質用字母寫：`maj7`、`m7`、`7`、`m7♭5`、`dim7`、`sus4`，不用 Δ、ø、° 這類符號（不同教材寫法不一樣，統一用字母）。
- 級數用大寫羅馬數字加性質：`Im7`、`V7`、`♭IIImaj7`。
- 和弦記號和級數放 `code`；句子裡順口提到的音名、調名不用（「從 B♭ 大調來」）。

## 一段話

- 一段一個意思，一到兩句。
- 一個小單元最多加粗一兩處，整段加粗等於沒加粗。
- 螢光筆（`mark`）一頁一處，給這頁最重要的那一句。
- 講解框的口吻見 [CHARACTER.md](CHARACTER.md#講解框的語氣)，其他地方用一般的說明口吻。

## 讀得進去

排版和字體都照規格，讀的人還是說「讀不進去」——毛病通常在文字。下面這幾條是改一份對照講義時整理出來的。

- **每頁先用一句話講完重點**，再展開。只讀第一句，也知道這頁在講什麼。
- **一句話只用一種語言當骨架。** 外文術語照上面「術語」的寫法放括號；外文原句另起一行，用小一號的灰字。三種語言擠在同一句裡最難讀。
- **少用「不是 A，是 B」。** 直接說是什麼。每用一次，讀者就要先讀一個錯的說法；只在讀者真的會誤會的地方用，一頁最多一次。
- **括號只放短的補充**：術語、年份、一兩個詞。超過一行就拆成獨立的一句。
- **出處、書目、ISBN、網址放附錄。** 正文留結論，加一句「見附錄」。查證過程夾在正文裡，主線會一直斷。
- **補充和原文分開標。** 原稿以外的頁面在小標旁加一個「補充」標籤，不要在句子裡反覆寫「這是本小姐補的」。
- **講解框一則講一件事。** 可以有個性，但不要編：沒有根據的推測（評分方式、會不會考、作者的意圖）不寫；真的要猜，就說是猜的。

虛構的例子：

- ✕ 這一頁**不是**在講**テンポ**（tempo，就是 BPM，每分鐘的拍數，出處見原稿第 4 頁的表和網址），**而是**在講**ノリ**。
- ○ 這一頁講的是律動感（ノリ）。速度只是其中一個條件，出處見附錄。

### 有原稿的對照講義

讀者手上有外文原稿（投影片、講義），要靠中文看懂它。

- **左右對照**：A4 橫式，左欄放原稿截圖（約 150mm 寬），下面接講解框；右欄放中文說明（約 110mm，一行三十幾個字）。上下排的話，眼睛要在圖和字之間來回找。
- **照原稿由上到下的順序講**，原稿上的每個框、每個紅字標註都要翻到。
- **圖上已經看得到的原文不用再抄**，給翻譯就好；要讀者抄寫或交出去的句子（題目、表頭）才附原文。
- 每頁頂端一行小標，寫「原稿第幾頁＋原稿標題」，拿著原稿也找得到。
- 外文片段加 `lang` 屬性（日文是 `lang="ja"`），才會用那個語言的字形和標點。

## 圖說與署名

- 圖說放在圖的下方，說「這是什麼、從哪裡來」，例如「原講義第 3 頁」。
- 用到角色素材就附署名，格式見 [README 的「署名與授權」](../README.md#署名與授權)。
- **第一行先寫自己**：`大肥魚（@Kujira-rice）／ Mizimo`，底下才是素材來源。
  素材授權要的是後面那幾行，但整段只有別人的名字，讀的人不會知道這是誰做的。
