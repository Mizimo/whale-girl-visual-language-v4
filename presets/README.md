# Presets ｜ 成品的做法

`templates/` 給的是版面；preset 給的是**「這份東西以前怎麼做的」**。

不是「A4 講義」這種體裁，是「Sound Engineering 的課，做成什麼樣」。
拿到一份材料，先找一個長得像的 preset，照它的規矩做。

## 目前有這幾個

| preset | 什麼成品 | 一句話 |
|---|---|---|
| [`sound-engineering/`](sound-engineering/) | 有原稿的課 → 原稿對照版 | 原稿在上面，中文在下面，一節一頁 |
| [`jazz-harmony/`](jazz-harmony/) | 會上好幾回的課 → 一套四件 | 地圖、術語、梳理卡、摘要，分開做 |
| [`max-msp/`](max-msp/) | 一套軟體怎麼接線 → handoff 骨架圖 | 字少、方塊大、做的時候擺旁邊 |
| [`math-for-programming/`](math-for-programming/) | 教科書的某一章 → 教材講解 | 一頁一件事，每頁收一句 |
| [`western-culture/`](western-culture/) | 圖和日文 → 圖解講義 | 一張圖配一段解釋，來源寫清楚 |

## 怎麼挑

看材料，不是看心情：

- 老師給的是**投影片 PDF**，讀者要照著念 → `sound-engineering`
- 一門課要**上十幾回**、以後還會回頭查 → `jazz-harmony`
- 內容是**一套軟體怎麼接線** → `max-msp`
- 材料是**教科書的某一章** → `math-for-programming`
- 材料是**圖和日文**，目的是看懂圖 → `western-culture`

找不到像的，就照下面「每個 preset 都長這樣」寫一個新的。

## 每個 preset 都長這樣

- **一句話**　這是什麼成品
- **必須有**　缺一不可的東西（這些是踩過坑才知道的）
- **絕對不要**　最常見的做壞方式
- **長相**　實際印出來的樣子，上面那張 `preview.png`
- **參照**　工作區或 repo 裡的實例
- **判斷**　怎麼知道做對了

## 新增一個 preset

1. 開一個資料夾，名字就是「這個成品叫什麼」（課名或專案名，不是體裁名）
2. `preview.png` 放**真的印出來的一頁**，不是畫示意圖
3. 照上面六段寫，規則要寫「會改變成品的」，不要寫排版教學
4. **不要放程式碼**——工具會換，做法不該跟著換
