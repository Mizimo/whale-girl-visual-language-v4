# Presets ｜ 成品長相

這些不是模板檔，是**成品規格**：拿到一份材料，最後應該做出什麼形狀的東西。

`templates/` 給的是 CSS 和骨架；preset 給的是頁序、每頁放什麼、什麼不要放。
一個 preset 讀完，換一個沒有上下文的 agent 也該做出八成像的成品。

## 目前有這幾個

| preset | 一句話 | 材料 | 成品 |
|---|---|---|---|
| [`slide-companion/`](slide-companion/) | 原稿在上面看得到，中文在下面讀得到 | 老師的投影片 PDF | A4 橫式，一節一頁 |
| [`lesson-notes/`](lesson-notes/) | 教材講成中文，加本小姐的聲音 | 教科書、長講義、課本頁 | A4 直向，一頁一件事 |
| [`cheat-sheet/`](cheat-sheet/) | 考前只看這一張 | 已經讀過的講義 | 一到兩頁的表 |
| [`study-pack/`](study-pack/) | 四份文件把一門課撐起來 | 一整學期的課 | 四個 markdown |
| [`side-by-side/`](side-by-side/) | 兩邊放在一起，一行對一行 | 兩份要對起來的東西 | 對照表或對照版 |
| [`reaction-paper/`](reaction-paper/) | 要交出去的那一張 | 課堂題目 | 一頁，留白給手寫 |

## 怎麼挑

1. 材料是**投影片**，而且想讓原稿跟中文同時在視線裡 → `slide-companion`
2. 材料是**書或長講義**，可以慢慢讀 → `lesson-notes`
3. 目的只是**考試前掃一眼** → `cheat-sheet`
4. 要**長期複習**、以後還會回頭查 → `study-pack`
5. 有**兩份東西要對起來**（原文／中譯、A 版／B 版） → `side-by-side`
6. 成品要**交出去給老師** → `reaction-paper`

同一個材料可以同時做好幾個。講義＋速查＋四件套是常態，不是重複做。

## 不管挑哪個，這四條都成立

1. **一頁一件事。** 塞不下就拆頁，不要縮字、不要壓行距。
2. **講解框一頁最多一個。** 它是聲音，不是第二個正文欄。
3. **術語原文優先。** 讀者考試用的是原文；中文只是幫他抓住意思。
4. **成品自己讀一遍。** 讀完會想繼續，就是對了；讀完像說明書，重做。

## 每個 preset 都長這樣

- **什麼時候用**　材料的形狀，不是主題
- **成品長相**　頁序、每頁有什麼、哪裡留白
- **參照**　本庫裡可以直接看的成品
- **規則**　會改變成品的幾條，不是排版教學
- **不做**　最常見的做壞方式

要加新的 preset，複製一個資料夾、照上面五段寫完就好。不要放程式碼進去——工具會變，成品長相不該跟著變。
