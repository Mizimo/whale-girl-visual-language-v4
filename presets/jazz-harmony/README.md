# 一套四件（jazz-harmony）

**一門課要上十幾回、以後還會一直回頭查，就用這個。**

## 一句話

不是「做一份講義」，是「把這門課整理成四份各司其職的文件」，再加每回的講義。

<img src="preview.png" width="688" alt="一套四件：地圖、術語表、梳理卡、摘要">

## 必須有

- **`00_地圖.md`**　這門課有什麼：講師、時段、講義清單、每一份現在做到哪。
- **`01_術語表.md`**　原文優先，三對照，每個加一行說明。越長越好。
- **`02_梳理卡.md`**　每回一張：這回在做什麼／逼自己想的問題／我想追問的。
- **`10_講義摘要.md`**　逐頁對應（p2、p6…），邊開 PDF 邊看。
- **每回的講義 HTML**　一頁一個概念，術語保留原文，重點用例子框。

## 絕對不要

- **四份互相抄。** 地圖抄摘要、摘要抄梳理卡，最後四份都一樣薄。
- **摘要沒有頁碼。** 回不到原稿的摘要，考試前沒用。
- **術語表只有中文。** 考試卷上印的是原文。

## 長相

四份 markdown 平鋪在資料夾，前面有數字排順序：`00` → `01` → `02` → `10`。
視覺化的講義另外放 `講義/`。

## 參照

- 工作區 `JazzHarmony2/`：`00_地圖.md`、`01_術語表.md`、`02_梳理卡.md`、`10_講義摘要.md`
- 講義：`JazzHarmony2/講義/第6回_講義_Modes.html`（9 頁）

## 判斷

翻開任何一份，都知道另外三份在哪、在講什麼。
不知道，就是地圖沒寫好。
