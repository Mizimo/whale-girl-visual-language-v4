# 教材講解（math-for-programming）

**材料是教科書的某一章，不是投影片。**

## 一句話

一頁一個概念。標題是一句「這頁要解決什麼」，頁尾一定收一句重點。

<img src="preview.png" width="688" alt="教材講解：標題、導讀、條列、例子、講解、重點框">

## 必須有

- **A4 直向。**
- **章節號 + 一句標題**（Ⅰ、Ⅱ…），標題寫「問題」，不是「第 3 節」。
- **導讀一句**：這頁在幹嘛。沒有這句，讀者不知道要讀多久。
- **例子／公式／程式碼**：看得到實際長的樣子，不是只有描述。
- **頁尾重點框**：兩到三條，這頁要記住的。
- **講解框**：卡住的地方才放，一頁最多一個。

## 絕對不要

- **逐段翻譯課文。** 那是翻譯，不是講解。
- **一頁放兩個概念。** 標題會變成「以及」。
- **只給公式不給例子。** 讀者會背，不會用。

## 長相

標題 → 導讀 → 條列或例子 → 講解 → 重點框。每頁都收在同一個形狀裡。

## 判斷

讀完那一頁，讀者能自己把那個例子算一次、寫一次。
做不到，就是例子太少或順序不對。
