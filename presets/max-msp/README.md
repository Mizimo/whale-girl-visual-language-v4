# handoff 骨架圖（max-msp）

**講一套軟體怎麼接線、怎麼跑，就用這個。**

## 一句話

把 patch 的骨頭交接出來：每個物件在幹嘛、哪裡可以改。
讀者做的時候把這頁擺旁邊，不用回頭翻講義。

<img src="preview.png" width="688" alt="handoff 骨架圖：四個節點由上往下，箭頭連起來">

## 必須有

- **一頁一個 patch，或一頁一個作業。**
- **節點鏈**：每個節點＝角色名（「大腦」「分派」）＋物件名（`mc.voiceallocator~ N`）＋一句話。
  角色名是給人記的，物件名是給手打的。
- **「差異在哪」一節**：兩個範例並排，指出**唯一**不同的地方。
- **字少、方塊大、箭頭粗。** 這是擺在旁邊對照用的，不是拿來讀的。

## 絕對不要

- **貼一張 patch 截圖叫人自己看。** 圖上沒有「這個在幹嘛」。
- **逐物件寫成 API 文件。** 那是官方 help 檔的工作。
- **只講輸入輸出，不講「哪裡可以改」。** 讀者是要動手，不是要考試。

## 長相

一頁：一句目的 → 四個節點（角色／物件／一句話）→ 一句「不整齊藏在第幾步」。

## 參照

- 工作區 `MaxMSP/講義/06_mc_fm_導覽.html`（1 頁，標註過的 patch）

## 判斷

讀者開著 Max，照著節點鏈就能把 patch 接出來。
卡住的地方，就是那一格沒寫清楚。
