# 對照表（side-by-side）

**兩邊放在一起，一行對一行。**

## 什麼時候用

- 原文／中譯要對起來讀。
- A 版／B 版（舊法／新法、兩種實作、兩種寫法）。
- 要看出差異，不是各讀一遍。

## 成品長相

**短的：兩欄對照**（一頁以內）

```
┌──────────────┬──────────────┐
│ 原文          │ 中譯          │
├──────────────┼──────────────┤
│ 第一句        │ 第一句        │
│ 第二句        │ 第二句        │
└──────────────┴──────────────┘
```

**長的：對照版文件**

封面 → 章節頁 → 每章兩欄或三欄（A｜B｜差異）→ 附註。

章節頁：大編號、章名、一句話，右下角一條尾巴。翻起來知道自己在哪。

## 參照

- 真實成品：30 頁的中譯對照（有章節頁、有譯者的話）、一份 Markdown 兩欄對照表
  （雲端有什麼／你手上有沒有）。
- [`examples/components.pdf`](../../examples/components.pdf)　兩欄對照、表格這幾種元件。

## 規則

1. **同一行對同一句。** 不要錯位；長句就先斷在同一個地方。
2. **左邊原文不動。** 要改、要補，寫在右邊或第三欄。
3. **差異用第三欄或底色標。** 不要用文字描述「這裡不一樣」——讀者要自己看出來。
4. **長文件每章一頁章節頁。** 短文件不要插，會空。
5. **標點、專有名詞照原文。** 連錯字都保留，另開一行註。

## 不做

- 不要把兩份混成一份重寫。對照的價值就在「還是兩份」。
- 不要改原文，連明顯的錯字都留著（在註裡說）。
- 不要對到一半就停；一半的對照比沒有更糟。
