# 原稿對照版（slide-companion）

**原稿在上面看得到，中文在下面讀得到。** 一份投影片拆成「一節一頁」，左邊中文、右邊講解。

## 什麼時候用

- 老師發的是**投影片 PDF**，不是教科書。
- 上課聽日文，回家讀中文。
- 複習的時候想讓「上課的畫面」跟「中文解釋」在同一個視線裡，不用兩個檔案來回翻。
- 原稿的圖、表、板書本身就是內容，不能只用文字重寫。

## 成品長相

A4 **橫式**。四種頁：

**一、封面**
圓形頭像、課名、回數、一句話說明這回在幹嘛；下面署名與授權。

**二、這一回在講什麼**
四格說明結構（定義／制度／自己練／書單之類），下面一框「怎麼讀這份」：原稿在上、中文在下、術語怎麼寫、校勘是什麼。

**三、一節一頁**（主體，佔全篇八成）

```
┌──────────────────────────────────────────────┐
│ 3. 三個名字，指同一個東西                      │
│ ┌──────────────────────────────────────────┐ │
│ │                                          │ │
│ │            原稿截圖（裁掉白邊）           │ │
│ │                                          │ │
│ └──────────────────────────────────────────┘ │
│ 原講義第 3 頁                      上為原稿，下為中文整理 │
│ ┌────────────────────────┐ ┌───────────────┐ │
│ │ 中文要點（3–6 條）      │ │ 本小姐的講解   │ │
│ │ ・術語（日文／English） │ │ 口語、可以吐槽 │ │
│ └────────────────────────┘ └───────────────┘ │
└──────────────────────────────────────────────┘
```

- 圖佔上半頁，**一定要裁掉白邊**再放大。
- 下半頁兩欄：左邊中文要點，右邊一框「本小姐的講解」。
- 圖說右邊寫「原講義第 N 頁」，右下角寫「上為原稿，下為中文整理」。

**四、術語表**
兩欄或四欄的對照表：中文｜日文｜English｜一句話。整份講義重複出現的術語都在這裡收。

頁序固定：封面 → 導讀 → 各節 → 參考文獻 → 術語表。

## 規則

1. **一節一頁。** 原稿幾頁就幾節；兩頁合併算一節，不要一頁塞兩節。
2. **原稿圖先裁白邊。** 白邊留著會讓字變小，整頁看起來像複印。
3. **術語第一次出現寫「中文（日文／English）」。** 不准只留片假名孤字；讀者聽的是片假名、看的是英文、考卷寫漢字。
4. **原稿有筆誤就標「校勘」。** 寫查證過的版本；查不到就說查不到，不要硬圓。
5. **參考文獻照原稿抄。** 自己補的標「（本小姐補的）」。
6. **圖太高就降圖高或合併兩頁。** 不要縮字、不要壓行距。
7. **一頁只放一個講解框。** 多了會失去焦點。

## 不做

- 不要把原稿每一行字都翻出來——原稿就在上面，讀者自己看得到。
- 不要重畫原稿的圖表。畫得再好也不是老師畫的那張。
- 不要為了塞進一頁而縮字。塞不下就拆頁。
- 不要放原稿沒有的圖；真的要放，標明是本小姐補的。
