# 原稿對照版（sound-engineering）

**老師給投影片 PDF 的課，一律這個做法。**

<img src="preview.png" width="688" alt="上面原稿、下面左中文右講解">

## 一句話

原稿在上面看得到，中文在下面讀得到。讀者能指著原稿說「這段在講這個」。

## 必須有

- **A4 橫式，一節一頁。** 不拆、不合併。
- **原稿截圖在上**，裁白邊、放到字看得清楚。
- **兩個圖說**：左上「原講義第 N 頁」，右上「上為原稿，下為中文整理」。
- **下面兩欄**：左邊中文（可以先一段話，再 bullet），右邊講解框。
- **術語不准留片假名孤字**：`長三和音（メジャー・トライアド／major triad）`。
- **最後一頁術語總表。**
- **筆誤標「校勘」**：寫查證過的版本，查不到就說查不到。

## 絕對不要

- 原稿濃縮成一張表——讀者是拿這份對照原稿看的。
- 一頁塞兩節。
- 查不到就硬圓。
- 截圖小到看不清字。

## 參照

`Sound Engineering/16/`（19 頁）、`Sound Engineering/第17回/`（13 頁）

## 判斷

把成品和原稿並排，讀者能不能指出「這句話對應哪一段」。
