# 圖解講義（western-culture）

**材料是圖和日文講義，目的是看懂圖。**

## 一句話

一頁一張圖。圖為什麼是證據，寫在圖下面。

## 必須有

- **封面一句總綱**（「羅馬人把馬賽克做到像照片；基督教把它變成黃金底上的符號」）。
- **標題 + 導讀一句。**
- **兩三條術語**：粗體 + 日文原文 + 英文。
- **圖置中**，下面圖說：`名稱（地點，年代）｜ 來源, 授權`。
- **證據框**（灰底）：這張圖為什麼是證據。
- **講解框**：給「轉折在哪」，不是重複圖片。

## 絕對不要

- 圖片不寫來源。
- 圖和解釋分家（圖在上面、解釋在下一頁）。
- 整段翻譯日文講義。
